# ELVAR — v1 / 0.12

Пересобранная версия ELVAR — сервиса случайных видеосвязей. В этой сборке интерфейс полностью заменён: без декоративных «человечков», без тяжёлой графики и с фирменным логотипом проекта.

## Что внутри

- Новый UI для стартового экрана и комнаты.
- Фирменный логотип из исходной аватарки, фон изображения удалён для использования на тёмном интерфейсе.
- Поиск по стране и взаимная проверка направления поиска.
- WebRTC peer-to-peer для аудио/видео.
- Локальный профиль: имя, email, страна, био, иконка или изображение.
- Чат через WebSocket с подтверждением доставки.
- Статус «Отошёл», реакции и локальные голосовые эффекты.
- RTT / voice-delay метрики.
- Перетаскиваемое превью своей камеры.
- Жалобы, feedback и защищённая admin-панель.
- Мини-игры Snake и Reaction.
- Быстрое переподключение WebSocket при потере сети.

## Важное исправление v1 / 0.12

Исправлена критическая ошибка инициализации Web Audio: пустой аудиограф раньше мог возвращаться вместо создания нового графа. Из-за этого голосовые эффекты и звуки реакций могли не запускаться при первом вызове.

Также сбрасывается состояние последнего сообщения, метрики очищаются при завершении сессии, добавлена обработка pointercancel для drag/PiP и закрытие модальных окон по Escape.

## Cloudflare

Сервис рассчитан на Cloudflare Workers + Durable Objects + Assets. Структура деплоя сохранена: Worker использует Durable Object `Lobby`, а статика лежит в `public/`.

Запуск после установки зависимостей:

```text
npm install
npm run check
npx wrangler dev
```

Для деплоя:

```text
npx wrangler deploy
```

### Переменные

Для admin-функций задаётся секрет `ADMIN_TOKEN`. Необязательная переменная `ADMIN_EMAIL` определяет адрес владельца. Для отправки email через Cloudflare Email Service используются binding `EMAIL` и `SUPPORT_FROM`.

## Ограничения

WebRTC по-прежнему использует STUN. Для более сложных NAT/корпоративных сетей публичному продакшену нужен TURN. Репозиторий не содержит сторонних TURN-учётных данных.
