# Changelog

## 1.0.12 — full rebuild

- Новый серверный слой аккаунтов и сессий.
- PBKDF2-хеширование паролей.
- Синхронизация профилей и списка аккаунтов на Durable Object.
- Админ-поиск по всем сохранённым пользователям + online-фильтр.
- Жалобы по категориям, частый reporter flow и агрегированный список тех, на кого жаловались.
- Группы, создание/вход/выход, теги и счётчик участников.
- Избранные собеседники с серверным хранением.
- Скрытая admin unlock форма + серверная проверка `ADMIN_TOKEN`.
- Admin действия: бан, разбан, force-next, удаление аккаунта, очистка жалоб и feedback.
- Сохранена фирменная графика ELVAR и исправлена связка favicon.
- Добавлены smoke/security/static проверки.
