# Changelog

## v1 / 0.12 — 2026-09-30

### UI
- Полностью заменён стартовый экран.
- Полностью переработана комната звонка.
- Убраны декоративные изображения людей.
- Добавлен фирменный логотип из предоставленной аватарки.
- Добавлена версия в интерфейс и новый layout для мобильных экранов.

### Stability
- Исправлена инициализация `AudioContext` / Web Audio graph.
- Состояние входящих chat message ID теперь корректно сбрасывается при новом peer.
- Метрики соединения сбрасываются перед новой сессией.
- Drag/PiP корректно обрабатывает `pointercancel`.
- Escape закрывает открытое модальное окно.
- Добавлены отдельные static/runtime smoke tests без внешних зависимостей.
